# Brainstorm

This skill is for brainstorming new solution ideas for the IMC 2026 Perception Loss Challenge. Enter a session and come up with novel ideas for mesh simplification that can be added to `docs/solutions.md`. Each idea should have a brief description and an initial status (e.g. "not started", "in progress", "completed").

## How to use

* Read `docs/problem-formulation-full.md` for a full description of the problem. Use `docs/math-formalism.md` for mathematical reference.
* Read `docs/solutions.md` for a list of solution ideas and their current status. 
* Invent new solution ideas and add them to `docs/solutions.md` with a brief description and initial status. Score and add notes to existing entries in `docs/solutions.md`.
* Refer to `docs/mesh-simplification-overview.md` for a comprehensive overview of mesh simplification techniques. This can be used for brainstorming new ideas.
* Explore underlying mathematical principles and algorithms in `docs/math-formalism.md` to inform your solution ideas.
* Connect to other fields, such as computer graphics, computational geometry, and optimization, to find inspiration for new solution ideas. Linear programming, graph theory, and numerical optimization techniques may provide useful insights for mesh simplification.
